# NeuralNetwork
ニューラルネットワークを理解するための記録としてのリポジトリです。  
学習目的のため、実用できるソフトウェアをこのリポジトリにアップする予定はありません。

## XOR.py
### 概要
NumPyのみで基礎的な3層のニューラルネットワークを実装し、XOR問題を解くものです。 
### 実行
```bash
pip install numpy
python3 XOR.py
```
### 仕様
- 初期値：Xavierの初期値
- 活性化関数：隠れ層出力層ともにシグモイド関数（標準ロジスティック関数）
- 損失関数：交差エントロピー誤差
- 最適化：勾配降下法
- 最大10000エポック（ただし、途中で損失が0.01未満になった場合は早期終了）。

隠れ層のノード数は変数で変えられますが、デフォルトはn=4です。
理論上は2ノードでも隠れ層がOR,NANDを出して出力層がANDを出せば解けるはずですが、初期値によっては鞍点や局所解に収束しやすかったため、4ノードにしています。

### 改善
この規模だとあまり問題になりませんが、標準ロジスティック関数は勾配消失が起きやすいため、以降の実験ではReLUでの実装に変更するかもしれません

## MNIST.py
### 概要
NumPyのみで単層パーセプトロンによりMNISTデータセットを学習し、その性能を評価するものです（正答率は大体80~85%くらい）。  
何やってるのかわからなくなってくるので、機械的に正答率を判定した後に、テストデータのインデックスを入力すると実際の画像と正解ラベルと推定された数字をmatplotlibによって表示する機能をつけておきました。
### 実行
事前にMNIST.pyと同じ階層にMNISTフォルダを作成し、データセット（画像/ラベル）とテストデータ（画像/ラベル）の4ファイル（それぞれgzip）を解凍した状態で入れておくこと
<pre>
MNIST.py
MNIST
├── train-images-idx3-ubyte
├── train-labels-idx1-ubyte
└── t10k-images-idx3-ubyte
└── t10k-labels-idx1-ubyte
</pre>
```bash
pip install numpy matplotlib
python3 MNIST.py
```
### 仕様
- 初期値：Xavierの初期値
- 活性化関数：Softmax関数
- 損失関数：交差エントロピー誤差
- 最適化：勾配降下法
- 最大50エポック（一応損失が0.01未満で終了するものの、多分早期終了はしない）
