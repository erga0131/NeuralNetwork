## XOR.py
### 概要
NumPyのみで基礎的な3層のニューラルネットワークを実装し、XOR問題を解くものです。 
### 実行
```bash
pip install numpy
python3 XOR.py
```
### 仕様
- 初期値：Xavierの初期値
- 活性化関数：隠れ層出力層ともにシグモイド関数（標準ロジスティック関数）
- 損失関数：交差エントロピー誤差
- 最適化：勾配降下法
- 最大10000エポック（ただし、途中で損失が0.01未満になった場合は早期終了）。

隠れ層のノード数は変数で変えられますが、デフォルトはn=4です。
理論上は2ノードでも隠れ層がOR,NANDを出して出力層がANDを出せば解けるはずですが、初期値によっては鞍点や局所解に収束しやすかったため、4ノードにしています。

→MNIST_MLP.pyでは隠れ層にReLUを利用した

## MNIST.py / MNIST_MLP.py
### 概要
- MNIST.py → NumPyのみで単層パーセプトロンによりMNISTデータセットを学習し、その性能を評価するものです（正答率は大体80~85%くらい）。  
- MNIST_MLP.py → MNIST.pyを多層パーセプトロン（隠れ層のノード数は512）に拡張したり、Heの初期値にしたり、ミニバッチ学習やAdamによる最適化を加えるなど改善したもの（正答率98.21%を記録）。  

何やってるのかわからなくなってくるので、機械的に正答率を判定した後に、テストデータのインデックスを入力すると実際の画像と正解ラベルと推定された数字をmatplotlibによって表示する機能をつけておきました。  
私の理解は画像を1x784で明るさを0~1に正規化して行列として並べた際、隠れ層の重み行列は数字が持つパーツの特徴を示すことになり、それを出力層の行列が受け取って、それぞれの特徴を持っているか否かである数字の出力を大きくするという重みが学習されているので、最大の値を取ることで数字が判定できるというものです。
### 実行
事前にMNIST.pyと同じ階層にMNISTフォルダを作成し、データセット（画像/ラベル）とテストデータ（画像/ラベル）の4ファイル（それぞれgzip）を解凍した状態で入れます
<pre>
MNIST.py
MNIST
├── train-images-idx3-ubyte
├── train-labels-idx1-ubyte
├── t10k-images-idx3-ubyte
└── t10k-labels-idx1-ubyte
</pre>
実行にはnumpyが、最後の実際の画像を表示するには追加でmatplotlibが必要です
```bash
pip install numpy matplotlib
python3 MNIST.py
python3 MNIST_MLP.py
```
### 仕様
- 初期値：Xavierの初期値(MNIST.py)、Heの初期値(MNIST_MLP.py)
- 活性化関数：Softmax関数(MNIST.py)、隠れ層ReLU+出力層Softmax(MNIST_MLP.py)
- 損失関数：交差エントロピー誤差
- 最適化：勾配降下法(MNIST.py)、確率的勾配降下法（ミニバッチSGD）+Adam（MNIST_MLP.py）
- MNIST.py：最大50エポック（一応損失が0.01未満で早期終了する機能はつけていますが、多分しません）
- MNIST_MLP.py：サイズ128でミニバッチ学習をする。これを20エポック

→ReLUを使ったMLPにしたところ、フルバッチのままでも91%程度までは精度が向上した

- ~~Adamを追加する~~

## Word2Vec.py
### 概要
Skip-gramで単語をベクトル化します。最後に単語を入力すると、コサイン類似度を計算して似ている言葉上位5つを表示します。  
私なりの理解
<pre>
言語学の分布仮説によれば、周囲の単語が似た環境で使われる単語は似たような意味を持つということになる。これら前後の単語を正解ラベルとして、中心となる単語の入力とペアにして行列にする。この行列を入力として2層のニューラルネットワークを通すと、1層目の行列はある単語が中心の単語として出てきた時のベクトル表現、2層目の行列はある単語が周辺の単語として解釈できる。ニューラルネットワークでは中心単語と周辺単語の内積を計算してSoftmax関数を通しているが、これは「ある中心単語に対して全語彙の中でその周辺単語が出現する条件付き確率」を大きくするように計算されているため、ペアとして出現したものは内積を大きく、ペアとして出現していない単語は相対的に内積が小さくすることができる。学習が進むにつれて、似たような周辺単語を予測する中心単語は似た更新を受けるため、入力側のベクトルも似た向きになっていく。この後、入力側の行列を取り出すことで、その単語が中心にある時のベクトルたちを取り出せる。なお、コサイン類似度は内積の式からコサインの値を逆に求めているだけなので、大きさを無視して向きの近さだけを計算できる。
</pre>
### 実行
事前にWord2Vec.txtと同じ階層にテキストファイルを作成し、filename = "sentence.txt"の部分をファイル名に変えます。
<pre>
Word2Vec.py
sentence.txt
</pre>
実行にはnumpyが必要です
```bash
pip install numpy
python3 Word2Vec.py
```
